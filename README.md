# Scenario Script Matcher for Trails in the Sky FC Evolution and Trails in the Sky the 1st

Thanks to KuroTools (nnguyen259/KuroTools). This script aims to parse the script text from files decompiled with KuroTools.

Python script to extract script text from decompiled scena files:
- `scena_voice_kuro_extractor.py`
Python script to match script text to Evo and find potential matching:
- `match_evo.py`
    - Option `-v`: Verbose mode.
    - Option `--no-similarity-search`: Disable similarity search.
    - Option `--similarity-threshold`: Set similarity threshold. Default is 0.85.


This repo use `uv` to manage virtual environment, and it uses Pytorch for CUDA 12.9 by default. Change the dependencies in `requirements.txt` to feed your needs.
```sh
uv pip install -r requirements.txt
```

Extracted script text:
- `scena_data_jp_add_struct.json`: Scenario script text extracted from `add_struct`s in decompiled scena files.
- `scena_data_jp_Command.json`: Scenario script text extracted from `Command`s in decompiled scena files.
- `scena_data_jp.json`: Both `add_struct`s and `Command`s.
- `scena_data_sc_add_struct.json`: Chinese Simplified Translations. Likewise.
- `scena_data_sc_Command.json`: Likewise.
- `scena_data_sc.json`: Likewise.

Matching Result:
- `match_result.csv`: CSV file containing matching results.
- `merged_voice_data.json`: Matched entries, in JSON format.
- `unmatched_voice_data.json`: Unmatched entries, in JSON format.
- `skipped_voice_data.json`: Skipped entries, in JSON format. Dummy.

About `match_result.csv`:
- `RemakeVoiceID`: Many of the text are not in the remake voice lists, so I create new voice IDs for each of them. Some text has corresponding Remake voice ID, their ID are set to the already existing ID. New IDs starts from 50001. You can apply filters on this column to focus on the new IDs.
- `RemakeScenaScriptFilename`: File basename of the source scenario decompiled script.
- `RemakeScenaScriptLineno`: Line number of the source scenario decompiled script.
- `RemakeScenaScriptAddStructLinenoOldScriptId`: Almost every Syscall `Cmd_text_00` and `Cmd_text_06` has a corresponding `add_struct` in the same file, which shares the same args with Syscall. This property is the line number of the corresponding `add_struct`.
- `OldVoiceFilename`: The voice file of the matched script.
- `MatchType`: The type of the match.
- `RemakeVoiceCategory`: The category of the matched voice. Always "evo".
- `RemakeVoiceTranslation`: The translation of the matched voice.
- `RemakeVoiceText`: The text of the matched voice.
- `OldVoiceText`: The text of the matched voice.
